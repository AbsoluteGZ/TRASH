# Простой бот для Telegram с курсом USD

Этот проект реализует простой бот для Telegram, который приветствует пользователя и выводит текущий курс обмена USD к RUB.

## Функциональность

Бот отвечает на команду `/start`, запрашивая имя пользователя. После получения имени (любое текстовое сообщение) он приветствует пользователя и отображает текущий курс USD к RUB, полученный из внешнего API.

## Зависимости

* `aiogram`: Для взаимодействия с Telegram ботом.
* `aiohttp`: Для асинхронных HTTP-запросов.

Установите их с помощью pip:

```bash
pip install aiogram aiohttp
```

## Настройка

1. **Токен API:** Замените на ваш реальный токен API Telegram Bot.  Вы можете получить этот токен у BotFather в Telegram.
2. **Запуск скрипта:** Запустите Python-скрипт. Бот начнет опрашивать обновления.

## Использование

1. Запустите бота.
2. Отправьте команду `/start`.
3. Бот спросит ваше имя.
4. Введите ваше имя.
5. Бот поприветствует вас и отобразит текущий курс обмена USD к RUB.

## API

Бот использует API `exchangerate-api.com` для получения курса обмена.  Используется конечная точка `/v4/latest/USD`. Ответ разбирается для извлечения курса RUB.  Включена обработка ошибок на случай сбоя API-запроса.

## Дальнейшее развитие

* **Обработка ошибок:** Можно реализовать более надежную обработку ошибок (например, обработка сетевых проблем, ограничений скорости API).
* **Дополнительные функции:** Бот можно расширить, добавив другие функции, такие как информация о погоде, конвертация валют для других валют и т. д.
* **Валидация ввода:** Можно добавить валидацию ввода, чтобы убедиться, что пользователь ввел допустимое имя.
* **Конфигурация:** Ключ API и другие настройки можно перенести в конфигурационный файл.
